# 構築・確認記録テンプレート

このファイルをコピーし、`YYYY-MM-DD-作業名.md` のような名前で保存します。パスワード、秘密鍵、トークン、個人情報は記録しません。実際に記入した例は [確認記録の記入例](./verification-record-example.md) を参照してください。

## 基本情報

| 項目 | 記入内容 |
|---|---|
| 作業名 | 例：Nginxのインストールと起動確認 |
| 実施日時 | YYYY-MM-DD HH:MM JST |
| 実施者 | 氏名 |
| 対象 | ホスト名、OS、学習環境 |
| 目的 | 何ができる状態にするか |
| 影響範囲 | 学習用VMのみ、など |
| 状態 | `NOT RUN` / `PASS` / `FAIL` / `PARTIAL` |

## 事前確認

- [ ] 対象が学習用環境である
- [ ] 実行するコマンドと影響を確認した
- [ ] 必要ならバックアップまたはスナップショットを用意した
- [ ] 元に戻す方法を確認した

## 実行内容

実行したコマンドを順番どおりに記録します。秘密情報は `<REDACTED>` に置き換えます。

```bash
# 実際に実行したコマンド
```

## 期待結果

- 例：サービス状態が `active (running)` になる
- 例：`127.0.0.1` からHTTP 200が返る

## 実際の結果

```text
必要な出力だけを貼り付ける
```

## 判定

- 状態：`NOT RUN` / `PASS` / `FAIL` / `PARTIAL`
- 根拠：どの出力から判断したか
- 未確認：まだ確認していないこと

## 復旧・ロールバック

問題が起きたときに戻した操作と、戻ったことの確認結果を記録します。
